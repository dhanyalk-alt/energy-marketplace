ENERGIX - LOCAL BACKGROUND VIDEO INSTRUCTIONS (LOCAL PC FILES ONLY)
========================================================================

All external CDN and third-party video links (YouTube, Vimeo, web streams)
have been removed. The background video now strictly supports ONLY local
PC video files (.mp4, .webm, .ogg).

------------------------------------------------------------------------
METHOD 1: PROJECT ASSET FOLDERS (Persistent Local Files)
------------------------------------------------------------------------
Place your video files in either of the following local project folders:

Folder A (Recommended):
  c:\Users\dhany\OneDrive\Desktop\grid_mp\energy-marketplace\public\assets\videos\

Folder B:
  c:\Users\dhany\OneDrive\Desktop\grid_mp\energy-marketplace\public\

Supported filenames & formats:
  - background.mp4
  - hero.mp4
  - background.webm
  - background.ogg
  - hero-video.mp4
  - hero-video.webm
  - hero-video.ogg

------------------------------------------------------------------------
METHOD 2: LOCAL PC FILE PICKER (Instant Playback)
------------------------------------------------------------------------
1. Open the Energix marketplace in your browser (http://localhost:5173).
2. Click the "(Change)" button next to the video badge in the bottom footer.
3. Click "Choose Local File (.mp4, .webm, .ogg)..." to select any video file
   directly from your computer.
4. It will immediately begin playing in full-screen loop without uploading
   to any external server.
